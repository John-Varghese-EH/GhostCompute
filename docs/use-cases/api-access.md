# Programmatic API Access

Since GhostCompute functions as a transparent Layer 7 HTTP multiplexer, any custom script, curl command, or application that can speak HTTP can communicate with your remote host. 

GhostCompute does not alter the requests—it only encapsulates them. This means you have 100% API compatibility with the underlying server (e.g., Ollama).

## Basic cURL Examples

Assuming GhostCompute is paired and running its local proxy on `127.0.0.1:11434` on your Client.

### 1. Check Version & Status
```bash
curl http://127.0.0.1:11434/api/version
```
*Returns the version of the Ollama instance running on the **Host** machine.*

### 2. List Available Models
```bash
curl http://127.0.0.1:11434/api/tags
```
*Lists all the models currently downloaded on the **Host** machine.*

### 3. Generate a Response (Streaming)
```bash
curl http://127.0.0.1:11434/api/generate -d '{
  "model": "llama3",
  "prompt": "Why is the sky blue?"
}'
```
*The response chunks will stream in real-time as they are generated by the Host's GPU, transported over the WebSocket, and un-encapsulated by your Client.*

## Python Example (using `requests`)

```python
import requests
import json

url = "http://127.0.0.1:11434/api/chat"
payload = {
    "model": "llama3",
    "messages": [
        {"role": "user", "content": "Write a haiku about computing."}
    ],
    "stream": False
}

response = requests.post(url, json=payload)
print(response.json()['message']['content'])
```

## Python Example (using `ollama-python`)

The official `ollama` Python library works flawlessly. Just configure its host:

```python
import ollama
from ollama import Client

client = Client(host='http://127.0.0.1:11434')

response = client.chat(model='llama3', messages=[
  {
    'role': 'user',
    'content': 'Hello from GhostCompute!',
  },
])
print(response['message']['content'])
```
